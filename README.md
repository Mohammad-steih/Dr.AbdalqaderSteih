# 🌐 Personal Portfolio Website

A modern, responsive, and multilingual personal portfolio website built with HTML, CSS, and JavaScript.

## 🚀 Features

- 🌍 Multilingual support
  - Arabic (AR)
  - English (EN)
  - Turkish (TR)

- 📱 Fully Responsive Design
  - Mobile Friendly
  - Tablet Optimized
  - Desktop Compatible

- 🎨 Modern UI/UX
  - Clean and Professional Design
  - Smooth Animations
  - Optimized User Experience

- ⚡ Fast Performance
  - Lightweight Structure
  - Optimized Assets
  - Fast Loading Speed

- 🔄 Language Switching
  - Seamless Language Change
  - RTL Support for Arabic
  - Consistent Layout Across Languages
